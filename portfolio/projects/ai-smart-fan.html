AI Smart-Fan — Infineon Technologies

Built a person-tracking, gesture-controlled fan on a 4-person team using an Infineon PSoC 6 evaluation kit and YOLOv10n on a Raspberry Pi 4B. Wrote the initial Python person-detection prototype (~0.5 fps, later optimized by teammates to ~10 fps), built the HTML/CSS web control interface, and co-authored the Hackster.io build guide.
